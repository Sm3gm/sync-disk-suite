# Sync Disk Suite

Three BepInEx plugins for Shadows of Doubt: 12 new sync disks, 37 split vanilla disks, and configurable vendor stock rotation.

Thunderstore page: https://thunderstore.io/c/shadows-of-doubt/p/Sm3gm/SyncDiskSuite/

The three plugins are independent. Each can be enabled or disabled on its own, and each has its own config file.

Requires BepInEx IL2CPP and SOD.Common by Venomaus.

Issues and bug reports are welcome on this repo.
